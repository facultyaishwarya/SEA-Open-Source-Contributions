Online College Canteen Food-Ordering System
1. Introduction to Mobile and Web Applications
A college canteen food-ordering system is an online platform that allows students to order food without standing
in long queues. Students can view the menu, select food items, make online payments, and receive notifications
when their orders are ready.
Mobile Application Software installed on smartphones. It can use device features such as notifications,
cameras, and GPS.
Web Application Software accessed through a web browser such as Chrome, Firefox, or Edge. It does not
require installation.
Progressive Web Application
(PWA)
A combination of mobile and web applications. It runs through a browser and offers
features such as home-screen installation and notifications.

3. Selection of Suitable Application
Recommended: Progressive Web Application (PWA)
A PWA is the most suitable choice for the college canteen food-ordering system for the following reasons:
• Students can access the application through a browser without downloading it.
• It can be installed on the mobile home screen like a normal application.
• It supports notifications to inform students when their food is ready.
• It works on different devices, including smartphones, tablets, and laptops.

• It is more affordable and easier to maintain than developing separate Android and iOS applications.
Therefore, PWA provides a cost-effective, user-friendly, and convenient solution for the college canteen.
4. Four Major Functionalities
1. Menu Browsing
• Display available food items.
• Show food prices and images.
• Display categories such as snacks, meals, and beverages.
• Show item availability.
2. Food Ordering
• Students can select food items.
• Add or remove items from the cart.
• Choose the required quantity.
• Place orders and receive order confirmation.
3. Online Payment
• Support UPI, debit cards, and other payment methods.
• Calculate the total bill automatically.
• Generate payment confirmation.
• Maintain payment records.
4. Order Tracking and Notifications
• Display order status.
• Notify students when food preparation starts.
• Send notifications when orders are ready.
• Display order history.
5. Three Major Development Challenges
1. Payment Security
• Protect students' payment information.
• Prevent unauthorized transactions.
• Use secure payment gateways.
• Handle failed and duplicate payments properly.
2. Real-Time Order Management
• Update order status immediately.
• Handle multiple orders at the same time.
• Avoid confusion between students and canteen staff.
• Manage food availability during peak hours.

7. Conclusion
A Progressive Web Application (PWA) is the best choice for developing the college canteen food-ordering
system. It provides the advantages of both mobile and web applications. Students can easily browse menus,
place orders, make payments, and receive notifications without installing a separate application.
It reduces waiting time, improves canteen management, and provides a convenient food-ordering experience for
students.
