1. Introduction to DevOps
DevOps is a combination of Development (Dev) and Operations (Ops). It is a software development approach that brings developers and IT operations teams together to develop, test, and deliver software faster and more efficiently.

In an online shopping application, DevOps helps developers frequently introduce new features, fix bugs, and update the application without delays.

It uses automation to reduce manual work and improve software quality.



2. Meaning of Continuous Integration and Continuous Delivery/Deployment

1. Continuous Integration (CI):
- Developers frequently merge their code changes into a shared repository.
- Every code change is automatically built and tested.
- Errors are identified early, making integration easier.

2. Continuous Delivery (CD):
- After successful testing, the application is automatically prepared for release.
- The software is kept ready for deployment.
- Deployment to production usually requires manual approval.


3. Continuous Deployment:
- Every code change that passes all automated tests is automatically deployed to the production environment.
- No manual approval is required.

  
3. CI/CD Pipeline Stages
The CI/CD pipeline consists of the following stages:
1. Code: Developers write and upload code to a shared repository using Git.
2. Build: The source code is compiled and converted into an executable application.
3. Test: Automated tests are performed to identify bugs and errors.
4. Release: The successfully tested application is prepared for deployment.
5. Deploy: The application is deployed to the production server.
6. Monitor: The application is continuously monitored to identify errors and performance issues.


4. Explanation of Build, Test and Deployment
1. Build:
- The source code is compiled using build tools.
- Dependencies are added, and an executable application is created.
- Example: Building a new version of the online shopping application.
2. Test:
- Automated testing checks whether the application works correctly.
- Unit testing, integration testing, and functional testing are performed.
- Example: Checking whether users can add products to the cart and complete payments.
3. Deployment:
- The successfully tested application is released to the production server.
- Users can access the latest version of the application.
- Example: Deploying an updated shopping application with a new payment feature.

  
5. Three Benefits of Automation
 Faster Delivery: Automation reduces manual work and helps release new features and updates quickly.

Improved Software Quality: Automated testing identifies bugs early and reduces human errors.

Increased Reliability: Automated deployment ensures consistent releases and reduces deployment failures.
